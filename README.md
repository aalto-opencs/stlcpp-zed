# STLC++ language support for Zed (`stlcpp`)

This repository contains a **Zed language extension** for **STLC++** (called `stlcpp` in this repo).

## Upstream references

- STLC++ implementation (parser + semantics): https://github.com/aalto-opencs/stlcpp
- STLC++ tree-sitter grammar: https://github.com/aalto-opencs/tree-sitter-stlcpp
